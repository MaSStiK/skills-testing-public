# Product Management Skills Assessment with a Leaderboard

</div>

**Product Management Skills Assessment with a Leaderboard** assesses product management skills using [ProductStar’s existing test](https://new.productstar.ru/test-for-product-camp2023#reg) with an added leaderboard. The participant’s goal is to reach the top of the leaderboard. The project took first place in ProductStar’s “Pet Project Exhibition” competition.

## ✨ Features

- The test can be taken an unlimited number of times; only the best result counts toward the leaderboard
- Questions and answer options are shuffled randomly each time the test is retaken

## 🎯 Project Goal

Turn the test into a complete product by adding a leaderboard that lets users view their results and see where they rank among other users who have taken the test.

## 📝 Project Tasks

1. Create a mechanism for collecting users’ results and compiling an overall leaderboard
2. Enable users to view their test results and position in the leaderboard
3. Develop an interface for viewing test results and the leaderboard
4. Ensure responsive design and cross-browser compatibility
5. Create server-side logic for collecting and storing test results
6. Design interface elements related to the leaderboard

## 👥 Target Audience

Participants attending ProductCamp online or in person:

- Product managers
- Project managers
- CPO
- Analysts
- Product designers

## ⚙️ How It Works

1. Before starting the test, the user views the product description and the participant leaderboard
2. The user registers by providing contact details; registration is required to take the test
3. After registering, the user takes the test and joins the participant leaderboard
4. After completing the test for the first time and viewing the leaderboard, the user should be directed to Wheel of Fortune, for example via a button, to spin the wheel and receive a prize
5. On the second and subsequent attempts at the test, participation in Wheel of Fortune is unavailable: this opportunity is offered only once

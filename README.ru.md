# Тестирование навыков продакта с рейтингом

</div>

**Тестирование навыков продакта с рейтингом** - тестирование навыков продакт-менеджмента на основе [готового теста ProductStar](https://new.productstar.ru/test-for-product-camp2023#reg) с добавленной рейтинговой системой. Цель участника - занять первое место в рейтинге. Проект занял первое место на конкурсе «Выставка Petомцев» от ProductStar.

## ✨ Возможности

- Тест можно проходить неограниченное количество раз; в рейтинг засчитывается только лучший результат
- При каждом повторном прохождении вопросы и варианты ответов перемешиваются в случайном порядке

## 🎯 Цель проекта

Превратить тест в полноценный продукт, добавив рейтинговую систему, которая позволит пользователям видеть свои результаты и место среди других участников, прошедших тест.

## 📝 Задачи проекта

1. Создать механизм сбора результатов пользователей и формирования общего рейтинга
2. Обеспечить возможность просмотра результатов теста и места в рейтинге
3. Разработать интерфейс для просмотра результатов теста и рейтинга
4. Обеспечить адаптивность и кросс-браузерную совместимость
5. Создать серверную логику для сбора и хранения результатов тестирования
6. Разработать дизайн элементов интерфейса, связанных с рейтинговой системой

## ⚙️ Механика использования

1. Перед началом тестирования пользователь знакомится с описанием продукта и рейтингом участников
2. Пользователь регистрируется, оставляя контактные данные; регистрация обязательна для прохождения теста
3. После регистрации пользователь проходит тест и попадает в рейтинг участников
4. После первого прохождения теста и просмотра рейтинга пользователя необходимо направить к «Колесу Фортуны», например с помощью кнопки, чтобы он мог прокрутить колесо и получить приз
5. При втором и последующих прохождениях теста участие в «Колесе Фортуны» недоступно: эта возможность предоставляется только один раз
